# SkillMirror — Frontend

Веб-приложение для подготовки к IT-собеседованиям. Платформа позволяет студентам и начинающим специалистам оценить свой уровень знаний, выявить слабые темы и получить приоритизированный план подготовки.

Данный репозиторий содержит **Frontend-часть** проекта.

## Стек технологий
* **React 18** (функциональные компоненты, хуки)
* **TypeScript** (строгая типизация)
* **Vite** (сборщик и dev-сервер)
* **React Router DOM v6** (маршрутизация)
* **Vanilla CSS** (Glassmorphism, адаптивная верстка)
